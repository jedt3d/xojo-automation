## Practical Conclusions

- `.xojo_*` is a family of formats, not one syntax.
- Text files are mostly combinations of `#tag` blocks, `Begin ... End` object trees, and `Key=Value` assignments.
- `.xojo_resources`, `.xojo_binary_project`, and `.xojo_uistate` are binary/opaque in this corpus.
- Preserve unknown flags, IDs, icon references, project item IDs, and compatibility expressions.
- Edit source only inside the intended tag block and run Analyze Project after Xojo reloads the project.
